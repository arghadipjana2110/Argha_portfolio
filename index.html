NetWatch — Enterprise Network Monitor
A full-stack PRTG-inspired network monitoring platform built with Python (FastAPI), SQLite, and Jinja2. Features 15 sensor types including ICMP Ping, HTTP/HTTPS, DNS lookup, SSL certificate expiry, SMTP, FTP, NTP, and bandwidth testing with APScheduler-based automated polling. Includes an alert rules engine with auto-fire/resolve logic, configurable thresholds, event logging, Docker containerization, and a dark cyberpunk dashboard UI.
